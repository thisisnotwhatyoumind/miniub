# Security

miniUB состоит из загрузчика и кода юзербота на GitHub. Загрузчик скачивает
`userbot.py` по сети, сверяет SHA-256 с хешем, зашитым в `.plugin`, и
выполняет код внутри процесса exteraGram. Песочницы нет: и юзербот, и
пользовательские модули имеют те же права, что и само приложение.

- Устанавливай только загрузчик из этого репозитория и только с ожидаемым
  SHA-256.
- Если файл `userbot.py` на GitHub изменён, загрузчик со старым хешем
  откажется его запускать — это защита от подмены.
- Не запускай код из непроверенных чатов и ссылок.
- Системные модули защищены от удаления командами, но это не заменяет
  проверку кода, который ты добавляешь вручную.

Если нашёл уязвимость, не публикуй её в открытом issue. Напиши владельцу
репозитория приватно и приложи минимальный сценарий воспроизведения.
